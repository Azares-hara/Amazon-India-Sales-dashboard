# Amazon-India-Sales-dashboard
A dashboard built using Excel and Google Sheets.
## KPIs
- Total Sales
- Total Profit
- Total Orders
- Units Sold
- Average Order Value
- Return Rate
- Cancellation Rate

## Visualizations
- Monthly Sales & Profit Trend
- Category-wise Units Sold
- State-wise Orders
- Payment Method Distribution
- Category-wise Returns & Cancellations
